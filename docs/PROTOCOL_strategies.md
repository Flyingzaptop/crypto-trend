# Протокол: 5 кандидатов во вторую стратегию (объявлено до запуска, 18.10.2026)

Монеты: BTC + ETH. Данные: минутки Binance spot → дневки / 4ч / 1ч; перп — дневные закрытия USD-M; фандинг USD-M.
Издержки 10 bp на единицу изменения позиции (для карри — на каждую ногу). Все направленные стратегии масштабируются на 20% вол.
(та же схема, что в `trend.target_positions`: равный риск монет, вол-таргет по 60 дням, потолок 1×), чтобы сравнивать с трендом.
Параметры заданы здесь и не подбираются.

1. **Фандинг-карри**: лонг спот + шорт перп на равную сумму, по BTC и ETH пополам, держим, если средний фандинг за
   7 дней > 0, иначе выходим. Доход = фандинг + (спот − перп). Без плеча, капитал = сумма спот-ноги. Масштаб на вол не делаем.
2. **Короткий возврат к среднему**: z = доходность дня / вол. 20 дней; позиция на следующий день = −clip(z/2, −1, 1).
   Вариант на 4ч барах (z по 120 барам).
3. **Сезонность**: (а) день недели, (б) час суток (по 1ч барам). На 2018–2023 считаем среднюю доходность каждого дня/часа;
   лонг 2 лучших дня / 6 лучших часов, шорт 2 худших дня / 6 худших часов. Проверка только на 2024–2026.
4. **Тренд на 4ч барах**: то же правило (SMA 20/50/100 баров, вол 20 баров, риск 60 баров), фандинг — дневной / 6 на бар.
5. **Фильтр фандинга для текущего тренда**: если средний фандинг за 7 дней выше 90-го перцентиля за прошедший год
   (только прошлые данные), лонг уменьшается вдвое (шорт не трогаем).

Оценка каждого (2018–2026 и 2024–2026): CAGR, Sharpe, просадка; корреляция дневных доходностей с текущим трендом;
**комбинация 50/50 по риску** (обе ноги на 20% вол., сумма снова на 20% вол.) против одного тренда.
Кандидат полезен, если комбинация на 2024–2026 даёт Sharpe выше одного тренда **и** корреляция < 0.5.
Для п. 5 — сравнение отфильтрованного тренда с исходным напрямую.

## Дополнение (объявлено до запуска): карри с редкими переключениями
Варианты: (0) исходный — 7д фандинг > 0; (а) всегда держим; (б) 30д фандинг > 0;
(в) гистерезис — входим, когда 30д > 0, выходим, только когда и 30д < 0, и 7д < 0.
Сравнение по годам 2020–2026 + число переключений. Выбор — вариант с лучшим Sharpe на 2024–26 при условии,
что он не хуже исходного на 2020–23 (иначе берём «всегда держим» как самый простой).

## Дополнение 2 (объявлено до запуска): кандидаты со стабильным во времени преимуществом
Критерий автора: доход стратегии не должен убывать год от года (карри отвергнут — доход падает каждый год).
Метрики по годам 2018–2026: Sharpe каждого года; **доля плюсовых лет ≥ 70%**; **наклон Sharpe по годам ≥ −0.05 в год**
(МНК); корреляция с текущим трендом < 0.5; комбинация 50/50 по риску даёт Sharpe выше одного тренда на 2024–26.
Для контроля те же метрики считаются для текущего тренда.
Кандидаты (параметры фиксированы):
1. **Тренд ETH/BTC** — то же правило на отношении ETH/BTC (лонг ETH / шорт BTC и наоборот).
2. **Пробой канала (Дончиан)** на BTC/ETH: лонг при закрытии выше максимума 50 дней, шорт ниже минимума 50 дней, иначе держим.
3. **Тренд на золоте** (PAXG/USDT) — то же правило.
4. **Тренд только в лонг** на BTC/ETH (сигнал < 0 → вне рынка).
