# X1 — медленные паттерны на традиционных рынках (протокол, зафиксирован до запуска)

**Данные.** Yahoo, дневные open/close (скорректированы на дивиденды и сплиты): SPY, QQQ, IWM, EFA, EEM, TLT, IEF, GLD, SLV, USO, DBC, UUP, FXE, FXY, VNQ. Издержки ETF — 5 bp на единицу изменения позиции, если не сказано иначе. Выбор и описание — ≤ 2023 (с 2008 года, когда доступны все тикеры), вердикт — 2024-01-01…сегодня.

**(а) TSMOM 12−1.**
- Сигнал на последний торговый день месяца: знак ln(P[m−1] / P[m−12]).
- Вес актива: сигнал × 0.40/σ60 / N, где σ60 — 60-дневная годовая волатильность, N — число активов с историей.
- Портфель масштабируется к 10% vol по скользящей 60-дневной волатильности портфеля (на момент ребаланса).
- Ребаланс раз в месяц, позиция держится до следующего ребаланса. Параметры фиксированы (классика Moskowitz–Ooi–Pedersen), без подбора.

**(б) Ночной эффект** SPY, QQQ, IWM, GLD.
- Лонг с закрытия до открытия: ln(open_t / close_{t−1}).
- Каждый день — полный оборот (вход и выход), издержки 2 × c на день; c ∈ {0, 1, 2, 5} bp на сторону.
- Реалистичным считаем c = 2 bp: спред SPY ~0.3 bp + проскальзывание на аукционах открытия и закрытия. Сравнение с купить-и-держать и с дневной частью (open→close).

**(в) Начало месяца** в SPY, QQQ, IWM.
- Лонг на последний торговый день месяца и первые 3 торговых дня следующего месяца, остальное время — кэш (ставка 0).
- Издержки 5 bp на вход и на выход. Сравнение с купить-и-держать.

**(г) Связка с трендом BTC+ETH** (`trend.py`, 20% vol; дневки крипты сведены к торговым датам ETF).
- Для каждого из (а), (б при c = 2 bp), (в) — 50/50 по риску. Веса берутся из волатильности ≤ 2023 и фиксируются.
- Лучшая связка выбирается по Sharpe 2018–2023, вердикт — 2024–26: Sharpe и максимальная просадка связки против тренда одного.

**Успех.**
- Для (а)–(в): Sharpe на 2024–26 > 0.5 и знак тот же, что на ≤ 2023.
- Для (г): связка улучшает и Sharpe, и просадку тренда на 2024–26.

**Счёт вариантов.**
- (а) 1;
- (б) 4 тикера × 4 уровня издержек — 16, для выбора годится только уровень c = 2 bp;
- (в) 3;
- (г) 3.
