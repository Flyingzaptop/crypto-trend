# ML2 — прямое предсказание редких входов (протокол, зафиксирован до запуска)

**Вселенная (на каждый день, без заглядывания вперёд, с делистинговыми).**
- BTC и ETH всегда.
- Плюс топ-10 по среднему 30-дневному спот-обороту среди монет, у которых на этот день уже есть перп (есть фандинг Binance USD-M).
- Без стейблкоинов, золота и плечевых токенов.
- Цены — дневные закрытия спота Binance (архив `archive_d1`, включая делистинговые). Это прокси цены перпа; издержки по перпу.

**События.** Симметричный CUSUM-фильтр по дневным лог-доходностям, порог = σ20 монеты (дневная):
- S⁺ = max(0, S⁺ + r);
- S⁻ = min(0, S⁻ + r);
- событие при S⁺ > σ20 или S⁻ < −σ20, затем сброс.

Только в дни событий модель может открыть сделку.

**Метка (triple barrier).** От закрытия дня события:
- верхний барьер +σ20·√H, нижний −σ20·√H, вертикальный — H ∈ {5, 20} дней;
- y = 1, если первым достигнут верхний барьер, y = 0 — если нижний;
- на вертикальном барьере y = 1, если доходность > 0.

**Признаки на t:**
- доходности 1/5/20/60;
- RV 5/20/60, RV20/RV60;
- расстояние до SMA 20/50/100 в σ;
- фандинг 1/7/30;
- ln(оборот / средний 30);
- бета и корреляция к BTC за 60 дн;
- доходность BTC 5/20;
- ранг оборота в вселенной;
- направление CUSUM-события;
- флаги BTC/ETH.

**Модели** (параметры фиксированы, не подбираются):
- LightGBM — как в ML1.
- MLP на torch (CPU): вход = признаки t + окно 60 дней из (доходность/σ20, ln оборот/средний), слои 64→32, dropout 0.2, Adam 1e-3, 30 эпох, batch 256, стандартизация по обучению.

**Walk-forward.** Переобучение раз в год, purge = H дней. Прогнозы 2020–2026.

**Торговля.**
- Сделка открывается, если |p − 0.5| ≥ 90-й перцентиль |p − 0.5| на обучающей выборке этого года («верхний дециль уверенности»).
- Сторона — sign(p − 0.5).
- Размер = 0.02 / (σ20·√H) (≈2% риска на сделку за горизонт), не более 0.5 от капитала.
- Выход — по барьеру или по вертикали, на закрытии.
- Сумма пересекающихся сделок, gross cap 2×.
- Издержки: 10 bp на вход и на выход, фандинг ежедневно.

**Выбор.** Из {LightGBM, MLP} × {H = 5, 20} = 4 вариантов выбирается один по Sharpe 2020–2023. Вердикт — 2024-01…сегодня.

**Базы:**
- купить и держать BTC+ETH 50/50;
- тренд `trend.py`;
- равновзвешенный лонг той же вселенной.

**Зеркало.** Выбранный вариант — обучение и тест на инвертированных ценах всех монет (фандинг с обратным знаком).

**Успех.** Выбранный вариант на 2024–26 одновременно:
- Sharpe > 0.5;
- Sharpe на зеркале > 0;
- 50/50 связка с трендом улучшает Sharpe тренда.

Иначе — провал.

**Счёт вариантов.** 4.
