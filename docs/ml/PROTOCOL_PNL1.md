# PNL1 — сеть оптимизирует P&L напрямую, без RL (протокол, зафиксирован до запуска)

**Вопрос.** Может ли небольшая сеть, обученная на дифференцируемом критерии прибыли (Sharpe, mean−variance, mean−drawdown), найти устойчивую позицию на BTC, ETH и золоте, которая лучше купить-и-держать и тренда?

## Рынки и бары

| рынок | бары | данные | издержки | фандинг |
|---|---|---|---|---|
| BTCUSDT, ETHUSDT | 1d, 4h | спот Binance REST (кэш `data/ml`) | 10 bp на единицу \|Δp\| | в оценке: дневной фандинг перпа, для 4h — /6 на бар |
| XAUUSD | H1, H4, D1 | M1 из Google Drive → бары `resample(...).last().dropna()` | 1 bp | нет |

У золота только реальные бары: выходные и паузы рынка — это одна доходность через разрыв.

## Модель позиции
- Решение на закрытии бара t: p_t = tanh(f(x_t, p_{t−1}, h_{t−1})) ∈ [−1, 1].
- P&L бара: p_t · (r_{t+1} − r̄_train) − c · |p_t − p_{t−1}|.
  - На обучении дрейф r̄_train вычтен, r нормированы на σ_train.
  - В оценке — сырые r, издержки и фандинг.
- **Позиция p_{t−1} — вход сети, рекуррентно для обеих архитектур.** Сеть разворачивается по времени через кусок (без teacher forcing): MLP получает [x_t, p_{t−1}] на каждом шаге, GRU — то же как вход ячейки плюс своё скрытое состояние. Градиент проходит через всю цепочку позиций. Так оборот и издержки учитываются честно.
- **Обучение** на непрерывных кусках по 256 баров со случайным началом, 64 куска в батче. Позиция и скрытое состояние в начале куска — 0.
- **Оценка** — один непрерывный проход по периоду, старт без позиции.

## Признаки (на закрытии t, только прошлое; стандартизация средним/σ обучения)
- σ — скользящая σ 1-бар доходностей за 100 баров.
- Доходности за n ∈ {1, 2, 4, 8, 16, 32, 64, 120} баров в единицах σ·√n.
- Расстояние до SMA n ∈ {20, 50, 100, 200}: (ln c − ln SMA_n) / (σ·√n).
- ln(σ_20/σ_100) и ln(σ_100/σ_500).
- Положение в диапазоне 20 и 100 баров (×2 − 1).
- Время: день недели sin/cos; для внутридневных баров ещё час суток sin/cos.

## Лоссы (4)
Все считаются на куске и усредняются по батчу; доходности нормированы на σ_train.
- **L1**: −mean / std P&L (Sharpe куска).
- **L2a**: −mean + 1·var.
- **L2b**: −mean + 5·var.
- **L3**: −mean + 1·MDD/L, где MDD — максимальная просадка накопленного P&L куска, L = 256.

## Модели (4)
- MLP: 2 слоя ширины {16, 64}.
- GRU: 1 слой {16, 64} + линейный выход.
- Общие настройки: dropout 0.2 на входе скрытого слоя, AdamW (lr 1e-3, weight_decay 1e-3).
- До 150 эпох (эпоха = 50 батчей). Ранняя остановка по Sharpe валидации (сырые r, издержки, фандинг): терпение 15 эпох, берётся лучшая эпоха.

Итого на рынок × бар 16 точек × 3 сида.

## Отрезки
- Обучение — с начала данных (крипта 2017-08, золото 2016-09) по 2022-12-31.
- Валидация 2023: ранняя остановка и **выбор точки** (лосс × модель) — по средней по сидам Sharpe валидации, отдельно для каждого из 7 рынков × баров.
- **Тест 2024-01 … последний бар — один раз, только для выбранной точки:** 3 сида и ансамбль (средняя позиция).
- **Walk-forward** для выбранной конфигурации: годы 2019…2026. Модель для года Y обучена на данных < Y−1, ранняя остановка по году Y−1, прогноз на год Y; 3 сида.

## Контроли
- **Альфа.** Альфа-Sharpe сверх купить-и-держать и сверх тренда: регрессия дневного P&L одновременно на дневную доходность купить-и-держать и тренда. Тренд для крипты — `trend.py` на одной монете (дневки, 20% vol); для золота — то же правило SMA 20/50/100 на дневках золота.
- **Плацебо.** Доходности бара перемешаны блоками по 20 баров (по всей истории). Из них собирается цена, по ней пересчитываются признаки и цели. Выбранная конфигурация обучается и оценивается так же; ожидание — Sharpe ≈ 0.
- **Разброс** по 3 сидам; оборот за год; время в рынке (|p| > 0.05); средняя |p|.
- **Дефлированный Sharpe** выбранных точек: N = 7 × 16 = 112 испытаний, дисперсия Sharpe испытаний — по Sharpe валидации всех точек.

## Успех (для рынка × бара)
На тесте одновременно:
- средний по сидам Sharpe > Sharpe купить-и-держать;
- альфа-Sharpe сверх купить-и-держать и тренда > 0.5;
- ≥ 2 из 3 сидов с альфой > 0;
- плацебо: Sharpe теста |SR| < 0.5;
- walk-forward: средний Sharpe 2019–2026 > 0.
