## Карри — подробнее
Доход по годам: 2020 +23.8%, 2021 +38.6%, 2022 −0.1%, 2023 +7.4%, 2024 +12.7%, 2025 +3.9%, 2026 ≈0% (фандинг ~2%/год,
издержки на частые входы/выходы). Худший день −1.2%, худший месяц −0.7%. Доход сильно зависит от бычьего рынка и падает со временем.

Совмещение по капиталу: тренд держит в среднем 0.32× капитала (макс 1×) на перпах — под маржу нужна малая часть капитала,
остальное может стоять в карри.

| | 2019-10…2026 CAGR / Sharpe / просадка | 2024–26 CAGR / Sharpe / просадка |
|---|---|---|
| Только тренд | 23.0% / 0.93 / 25.8% | 24.5% / 0.97 / 22.5% |
| Тренд + 50% капитала в карри | 29.9% / 1.17 / 25.0% | 28.0% / 1.09 / 19.0% |
| Тренд + 80% капитала в карри | 34.2% / 1.32 / 24.5% | 30.2% / 1.17 / 17.5% |

Оговорки: закрытия спота и перпа по дневкам (реальный базис внутри дня шире), не учтены риск биржи/контрагента,
ликвидация шорт-ноги при резком росте (нужен запас маржи), заём/перевод между кошельками. Порог входа «фандинг 7д > 0»
не подбирался; в 2026 он даёт много переключений — следующий шаг: держать постоянно или с гистерезисом (отдельный тест).
