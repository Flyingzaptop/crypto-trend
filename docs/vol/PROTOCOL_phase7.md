# Фаза 7. Крипта на реальных ценах Deribit (объявлено до запуска, 19.10.2026)

(а) Реальная IV сделок против Б–Ш по DVOL, спреды, перепрогон прошлого теста — по протоколу `PROTOCOL_phase0.md`
(записан до запуска, коммит be8e0a2); код `phase0.py`.

(б) **Недельный ATM-стрэддл с дельта-хеджем перпетуалом.**
* Вход: каждую пятницу 08:00 UTC (сразу после экспирации), экспирация — следующая пятница 08:00. BTC и ETH отдельно.
* Страйк — ближайший к индексу из тех, по которым в окне 08:00–10:00 были сделки и по коллу, и по путу этой экспирации.
  Цена входа — медиана mark_price сделок по ноге в окне ± измеренная половина спреда (медиана по ATM, срок 4–10 дней,
  только сделки до 2024 — из части (а)); IV входа — обращением Б–Ш из mark.
* Направление: (0) всегда продавать; (1) по знаку прогнозной премии HAR: продавать, если log IV_ATM − log прогноз HAR(7 дней) > 0,
  иначе покупать. Выбор варианта — по Sharpe до 2024, вердикт — 2024–2026.
* Хедж: дельта Б–Ш (σ = IV входа), пересчёт раз в сутки в 08:00 UTC по цене Binance; хедж перпетуалом, издержки 5 bp (тейкер)
  и 2 bp (мейкер) на оборот хеджа, фандинг по фактическим ставкам Binance.
* Расчёт: при экспирации — внутренняя стоимость по цене Binance в 08:00 (прокси индекса Deribit). Комиссии Deribit: 0.03%
  базового на ногу (не больше 12.5% цены опциона) на входе, 0.015% при расчёте (тот же потолок).
* Размер: номинал 1× капитала на сделку (одна единица базового на капитал). Метрики: доход за неделю в % номинала,
  Sharpe (52 недели), худшая неделя, макс. просадка, по годам, корреляция с крипто-трендом.
* Критерий: на 2024–2026 Sharpe ≥ 0.7, просадка ≤ 25%, не держится на одном годе.
