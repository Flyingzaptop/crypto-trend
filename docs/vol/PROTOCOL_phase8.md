# Фаза 8. Шорт новых листингов на перпетуалах Binance (объявлено до запуска, 19.10.2026)

Гипотеза: новые токены после листинга в среднем дешевеют (малая доля в обращении, разлоки, продажи фондов). Листингов
становится больше — эффект может не угасать.

## Данные
* Все перпетуалы USD-M к USDT из архива data.binance.vision, **включая делистинговые** (нет ошибки выжившего);
  дневные свечи 1d (закрытие 00:00 UTC), фандинг — фактический по каждому символу.
* Листинг = первый день с котировкой перпа; берутся листинги 2021-01 … 2026-08. Исключаются BTC, ETH, стейблкоины,
  токенизированные акции/золото, контракты-дубли с множителем (1000…, 1M…) — если базовый актив уже торговался.

## Стратегия
* Шорт каждого нового перпа со дня L + k (k ∈ {1, 7} дней после листинга) на H дней (H ∈ {30, 90, 180}).
* Портфель: равные веса по всем открытым шортам, суммарно 100% капитала в шортах (при одном шорте — 100%, при 10 — по 10%);
  потолок на один символ — 20% капитала (остаток — в кэше). Пересчёт весов ежедневно.
* Варианты: без хеджа; с хеджем — лонг BTC перп на ту же сумму (рыночно-нейтрально).
* Издержки: тейкер 5 bp на изменение позиции; фандинг: шорт получает положительный фандинг и платит отрицательный.
* Выбор (k, H, хедж) — по листингам с датой до 2024-01-01 (лучший Sharpe), вердикт — по листингам 2024–2026.

## Метрики и критерий
CAGR, Sharpe, макс. просадка, худший месяц, доход по годам; средний доход одного шорта за H дней (медиана и среднее —
из-за редких взлётов), доля «взлётов» > +100%.
Работает, если на 2024–2026 Sharpe ≥ 0.7, просадка ≤ 35% и обе половины 2024–2026 в плюсе.
