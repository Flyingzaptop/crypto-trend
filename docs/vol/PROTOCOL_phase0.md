# Фаза 0. Проверка симулятора опционов на реальных ценах Deribit (объявлено до запуска, 19.10.2026)

Вопрос: насколько Блэк–Шоулз с σ = DVOL (без улыбки) ошибался в ценах, и была ли синтетика прошлого теста
(`docs/RESULTS_vol.md`) оптимистичной или пессимистичной.

## Данные
* Сделки опционов BTC и ETH: `history.deribit.com/api/v2/public/get_last_trades_by_currency_and_time`, kind=option.
  Поля: время, инструмент (экспирация, страйк, тип), цена, mark_price, iv сделки, index_price, направление тейкера, объём.
* Выборка: (а) каждая пятница 2021-04 … 2026-10, окно 06:00–10:00 UTC (вокруг экспирации 08:00 — естественный вход
  недельных опционов); (б) каждая среда, одно окно 1 час в случайный час (seed 0) — проверка влияния времени суток.
* Фильтр: срок 1–60 дней (истекающий контракт исключён), цена > 0, mark_price > 0.
* DVOL — часовые значения Deribit, берётся последнее значение до сделки.

## Измерения
1. **Улыбка.** mark IV — обращением Б–Ш из mark_price (F = index_price, r = 0). Отношение mark IV / DVOL по
   стандартизованной денежности x = ln(K/F)/(DVOL·√T) (корзины −3…+3 шаг 0.5), сроку (1–3, 4–10, 11–30, 31–60 дней)
   и режиму DVOL (терцили за всю выборку).
2. **Спред.** Половина спреда ≈ (цена сделки − mark)·знак тейкера (покупка +, продажа −), в % от mark и в BTC;
   медиана по корзинам денежности и срока.
3. **Поправка.** Регрессия log(mark IV/DVOL) = полином 3-й степени по x × корзина срока + режим (дамми),
   обучение только на сделках до 2024-01-01; проверка точности на 2024–2026 (MSE).
4. **Перепрогон прошлого теста** (кондор неделя k=0.5 w=1.0, кондор месяц k=1 w=1, стрэддлы; правила выходов те же,
   вход прежний — для чистого сравнения цен): цены ног — Б–Ш с σ = DVOL · поправка(x, T, режим); спред-буфер 5%
   заменён измеренной половиной спреда (по корзине, не меньше минимального шага цены 0.0001 BTC); комиссии те же.
   Дополнительно — тот же перепрогон с удержанием до экспирации.

## Ответ фазы
Синтетика была оптимистичной / пессимистичной и насколько: разница Sharpe и CAGR на 2021–2026 и 2024–2026 между
старыми и поправленными ценами. «Заметно пессимистичной» = поправленный выбранный кондор на 2024–2026 лучше старого
на ≥ 0.3 Sharpe — тогда по правилу координатора сразу фаза 3.
