# Протокол: расширение пула монет (объявлено до запуска, 18.10.2026)

Цель: проверить, улучшает ли добавление монет к BTC+ETH результат стратегии. Правило позиций (`trend.target_positions`)
не меняется. Параметры: 20% вол., потолок 1×, комиссия 10 bp, фандинг перпетуалов учтён.

## Обобщение на N монет (единственное изменение кода правила)
Каждая монета входит в портфель, когда у неё появляется сигнал (≈130 дней истории: 100 на SMA100 + 30 на оценку её риска). Доля риска = 1 / (число монет
с сигналом на этот день), вместо фиксированного 1/2. Для BTC+ETH результаты обязаны совпасть с текущими (проверяется тестом).

## Кандидаты
* Binance spot, пары к USDT, средний дневной оборот за последние 30 дней, по убыванию.
* Исключены: стейблкоины и фиат (USDC, FDUSD, USD1, RLUSD, EUR, TUSD, …), токенизированное золото (PAXG, XAUT),
  токенизированные акции (…B: NVDAB, TSLAB, …), монеты без бессрочного фьючерса USD-M на Binance (без него нельзя шортить).
* Нужно ≥ 1 года истории на споте. Берём первые 100 по обороту, прошедшие фильтр.
* Данные: минутки (1m) из data.binance.vision → дневные закрытия 00:00 UTC.

## Процедура (жадный отбор, по совету автора)
1. BTC отдельно — база.
2. Порядок проверки: BTC, ETH, затем остальные по убыванию оборота.
3. Для кандидата X: портфель «текущий пул + X» против «текущий пул». Сравнение по календарным месяцам, в которых
   X полный месяц был в портфеле (после прогрева ≈130 дней).
   * Δ_m = месячная доходность (пул+X) − месячная доходность (пул), обе после издержек, при одинаковой целевой волатильности.
   * **Как часто лучше**: доля месяцев с Δ_m > 0.
   * **Насколько лучше**: среднее Δ_m (в % годовых) и разница Sharpe на общем периоде.
4. **X остаётся в пуле, если**: доля месяцев лучше > 50% **и** среднее Δ_m > 0; минимум 12 месяцев сравнения
   (иначе — «мало данных», не добавляем).
5. Итог — пул и его результат против BTC+ETH.

## Контроль переобучения (обязателен, тоже объявлен заранее)
Жадный отбор из 100 кандидатов на одних и тех же данных почти гарантированно найдёт «полезные» монеты случайно.
Поэтому:
* **Вне выборки:** та же процедура только на данных до 2023-12-31 (кандидаты с ≥ 12 месяцами сравнения до этой даты).
  Отобранный пул проверяется на 2024-01 … 2026-10 против BTC+ETH. Главный критерий — результат здесь.
* **Ошибка выжившего:** список берётся по сегодняшнему обороту, т.е. включает только выживших. Это завышает результат
  альтов (см. VALIDATION.md: честный тест альтов дал Sharpe 0.21 на 2024–26). Вывод делаем с этой поправкой.
* Издержки 10 bp для мелких альтов занижены; дополнительно — прогон итогового пула при 20 bp.
