# scripts/

## earnings_collector.py — ожидаемое движение по опционам перед отчётностями

Только стандартная библиотека Python 3.8+ (pandas не нужен). Источники без ключей: календарь отчётностей Nasdaq
(`api.nasdaq.com`, время BMO/AMC), цепочки опционов и дневные цены Yahoo Finance (cookie + crumb).

```bash
python scripts/earnings_collector.py              # снимок: отчёты на сегодня (после закрытия) и 10 торговых дней вперёд
python scripts/earnings_collector.py --outcomes   # реальное движение по прошедшим отчётам из всех снимков
```
Запускать раз в день после закрытия рынка США (например, 22:30 по Варшаве), сначала снимок, потом `--outcomes`.

* Вселенная: S&P 500 + Nasdaq-100 из Википедии (кэш `data/earnings/universe.csv`; если Википедия недоступна и кэша нет —
  компании с капитализацией ≥ $10 млрд).
* `data/earnings/snapshots_YYYYMMDD.csv` — строка на (компания, экспирация, страйк): спот, ближайшая экспирация после
  дня реакции (`post`) и последняя до него (`pre`), страйки ATM и ±1, bid/ask/last/IV колла и пута, стрэддл mid/bid/ask,
  `implied_move_pct` = ATM-стрэддл mid / спот (только для ATM). День реакции: BMO — день отчёта, AMC/неизвестно — следующий
  торговый день (праздники не учитываются).
* `data/earnings/outcomes.csv` — закрытие накануне реакции, открытие и закрытие дня реакции, движение в %.
* Ошибки по тикеру пишутся в stderr и пропускаются; паузы 0.4 с между запросами, повторы с ожиданием при 429/5xx.
* Параметры: `--out DIR`, `--days N`, `--max N` (ограничить число тикеров для проверки).
